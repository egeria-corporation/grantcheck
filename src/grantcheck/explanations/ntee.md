# NTEE classification

**What it checks.** The National Taxonomy of Exempt Entities code the IRS has on file for
this organization.

**Why it matters.** Program officers and automated eligibility filters both use the NTEE
code, so an inaccurate one can quietly keep an organization out of searches it belongs in.

**Why it is informational only.** NTEE codes are self-reported at the time of application
and are frequently out of date. A missing code is common and is not a problem in itself.
This check never fails.

**What to do.** If the code no longer describes the work, an organization can ask the IRS to
correct it.
